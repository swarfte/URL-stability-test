# URL 穩定性測試 App — Implementation Plan

## Context
Greenfield Flutter 3.44.6 / Dart 3.12.2 project. Currently only the default Material counter app exists. Spec (project-spec.md, sections 1–27) is highly prescriptive, including the directory layout (§18) and implementation order (§26). I'll implement the full MVP following §26's order, committing in logical chunks.

## Decisions (confirmed)
- **State management:** `ChangeNotifier` + `StabilityTestController` (simplest testable, no extra deps; controller named per §18).
- **HTTP:** `package:http` (spec §2.1). Service takes an injectable client factory so logic is unit-testable with `MockClient`/`MockClientStream`.
- **Local storage:** `shared_preferences` (simple key-value, spec §16 permits).
- **Chart:** `fl_chart` (`LineChart`) for the latency trend (§11.4) — colored + shape-coded points, axis labels, hover/click tooltips.
- **UI text:** Traditional Chinese per spec, as in-code constants (no i18n package for MVP).
- **Architecture strict per §18:** UI never does HTTP; stats never in widgets; URL validation standalone; HTTP logic unit-testable; controller owns session/progress/cancel; models depend on no widgets.

## Dependencies to add (`pubspec.yaml`)
- `http: ^1.4.0`, `shared_preferences: ^2.3.0`, `fl_chart: ^0.70.0` (+ keep `cupertino_icons`). Dev: keep `flutter_lints`.

## File plan (mirrors §18)

**Services** (pure/testable)
- `url_validation_service.dart` — returns validation result; auto-prepend `https://` unless `http://` already present; rules §6.1.5; error-message table
- `statistics_service.dart` — avg, min, max, median, P95 (nearest-rank §10.5), jitter (§10.6), successRate (§10.7); microsecond precision, `N/A` handling (§10.8)
- `stability_test_service.dart` — the runner: sequential requests, reuse vs new-client (§6.2.1/6.2.2), monotonic `Stopwatch` timing (§8.5), streamed body read with 10 MiB cap (§8.6), redirect limit 5 (§8.4), per-request timeout (§6.5), cancellation, interval wait between requests (§6.4 definition). **Widgets** (`widgets/`)

## Platform config (§20)
- **Android** `AndroidManifest.xml`: add `<uses-permission android:name="android.permission.INTERNET"/>`. Keep default cleartext policy (HTTPS-first; HTTP blocked → understandable error, §20.1). Do not globally relax TLS or cleartext.
- **macOS** `DebugProfile.entitlements` + `Release.entitlements`: add `com.apple.security.network.client = true`.
- **Windows** `win32_window.cpp`: handle `WM_GETMINMAXINFO` to enforce ~700×600 min window (§12.3); set default size.

## Tests (§22)
- **Unit:** `url_validation_service_test.dart` (auto-https, empty, bad scheme, missing host, userinfo), `statistics_service_test.dart` (avg, median odd/even, min/max, P95, jitter, successRate, zero/single success).
- **Service:** `stability_test_service_test.dart` using `MockClient`/`MockClientStream` — reuse vs new client, sequential order, interval, continue-after-timeout, continue-after-error, no-request-after-cancel, redirect limit, stream body full read, >10 MiB abort, client closed.
- **Widget:** `test_setup_screen_test.dart` — button disabled on invalid / enabled on valid, mode switch, count select. `test_result_screen_test.dart` — N/A on empty, list expand.
